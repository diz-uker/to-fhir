# DizUker.ToFhir

API reference for the C# port of [to-fhir](https://github.com/diz-uker/to-fhir), built on the
[Firely SDK](https://github.com/FirelyTeam/firely-net-sdk).

See the [project README](https://github.com/diz-uker/to-fhir/blob/master/README.md#usage-c)
for installation instructions and usage examples.

Start with the <xref:ToFhir> namespace for the full type list.
